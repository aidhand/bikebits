# BikeBits

Motorcycle gear catalog + AU price tracker. Indexes products across Australian
retailers, tracks variant prices over time, and emails price alerts.

## Stack

- Nuxt 4.5 + Nuxt UI 4
- Postgres + Drizzle ORM (`server/db/schema`)
- better-auth (email/password + verification/reset, Drizzle adapter)
- Resend for transactional mail (`server/utils/mail.ts`; `MAIL_DEV=true` logs instead of sending)
- Hybrid scraper: static fetch + cheerio first, Playwright/Chromium fallback (`server/scrapers`)
- Nitro scheduled tasks for nightly snapshots + alerts

## Setup

```bash
bun install
docker compose up -d db            # Postgres on localhost:5432
cp .env.example .env               # then adjust
bun run db:generate && bun run db:migrate
```

`.env` keys:

| Key | Meaning |
|---|---|
| `DATABASE_URL` | Postgres connection string |
| `BETTER_AUTH_SECRET` | Session/cookie secret (random hex) |
| `BETTER_AUTH_URL` | Base URL for auth callbacks |
| `RESEND_API_KEY` | Resend API key (empty + `MAIL_DEV=true` → console mail) |
| `MAIL_FROM` | From address for outgoing mail |
| `MAIL_DEV` | `"true"` logs emails to the server console instead of sending |

## Dev workflow

```bash
bun run dev                              # http://localhost:3000
curl -X POST http://localhost:3000/_nitro/tasks/catalog:seed    # categories + retailers
curl -X POST http://localhost:3000/_nitro/tasks/prices:snapshot # scrape + ingest
curl -X POST http://localhost:3000/_nitro/tasks/watch:alerts    # send watch alerts
```

Schedules (`nuxt.config.ts`): `prices:snapshot` nightly at 02:00, `watch:alerts` at 03:00.

## Scrapers

Adapters live in `server/scrapers/retailers/` and map `adapterId → RetailerScraper`
(see `server/scrapers/types.ts`). Politeness: max 1 req/s per host, robots.txt
honoured (`server/scrapers/http.ts`). Prices are stored as integer cents AUD.

- `mcas.ts` — schema.org microdata tiles on category pages, JSON-LD product page
- `bikebiz.ts` — CollectionPage JSON-LD for category URLs, ProductGroup JSON-LD per variant

To add a retailer: write an adapter, register it in `retailers/index.ts`, and seed
its `retailers` row (`catalog:seed`).

## Schema

`catalog.ts` (categories/brands/products/variants/retailers/listings/price_snapshots),
`watchlist.ts` (watch_items/alerts_sent), `auth-schema.ts` (generated by
`bunx @better-auth/cli generate`).

Variant uniqueness `(product_id, colour, size)` and listing uniqueness
`(retailer_id, variant_id)` make ingest idempotent; every run appends a
`price_snapshots` row per listing.
